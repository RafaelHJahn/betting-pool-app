**Issue:** [BOL-107](https://rafaelhjahn.youtrack.cloud/issue/BOL-107)

## Objetivo

Configurar Playwright para testes end-to-end no `betting-pool-app`, com um smoke test que valida o build estático de produção (`out/`) — página inicial renderiza título, heading e botão.

## Decisões de design

| Decisão            | Escolha                                                        |
| ------------------ | -------------------------------------------------------------- |
| Runner             | `@playwright/test` (latest)                                    |
| Browsers           | Chromium only                                                  |
| Servidor           | `webServer` faz `build` + `serve out` na porta `3000`          |
| Servidor estático  | `serve` como devDependency (também usado no script `start`)    |
| Local dos testes   | `e2e/*.spec.ts` (convenção Playwright)                         |
| Smoke test         | `<title>`, `<h1>Bolão</h1>`, botão "Entrar"                    |
| ESLint             | `eslint-plugin-playwright` + `playwright/valid-title`          |
| lefthook           | Incluir `e2e/` no glob ESLint; E2E só via `pnpm test:e2e` / CI |
| CI / multi-browser | Fora do escopo (BOL-108)                                       |

## Stack de ferramentas

## `playwright.config.ts`

```ts
import { defineConfig, devices } from "@playwright/test";

const PORT = 3000;
const baseURL = `http://localhost:${PORT}`;

export default defineConfig({
  testDir: "./e2e",
  fullyParallel: true,
  forbidOnly: !!process.env.CI,
  retries: process.env.CI ? 2 : 0,
  workers: process.env.CI ? 1 : undefined,
  reporter: "html",
  use: {
    baseURL,
    trace: "on-first-retry",
  },
  projects: [{ name: "chromium", use: { ...devices["Desktop Chrome"] } }],
  webServer: {
    command: `pnpm build && pnpm exec serve out -l ${PORT}`,
    url: baseURL,
    reuseExistingServer: !process.env.CI,
    timeout: 120_000,
  },
});
```

- `timeout: 120_000` — margem para o `next build` no primeiro run
- `reuseExistingServer: !process.env.CI` — em dev, reutiliza servidor se `pnpm start` já estiver rodando na porta 3000
- `forbidOnly` / `retries` — preparado para BOL-108, sem custo local

## Smoke test — `e2e/home.spec.ts`

```ts
import { expect, test } from "@playwright/test";

test.describe("Homepage", () => {
  test("should render title, heading and enter button", async ({ page }) => {
    await page.goto("/");

    await expect(page).toHaveTitle("Bolão");
    await expect(page.getByRole("heading", { name: "Bolão", level: 1 })).toBeVisible();
    await expect(page.getByRole("button", { name: "Entrar" })).toBeVisible();
  });
});
```

Valida: Playwright + build estático + `serve` + seletores acessíveis (`getByRole`).

## ESLint — bloco Playwright

Novo bloco após o bloco Vitest existente:

```js
import playwright from "eslint-plugin-playwright";

// ...

{
  files: ["e2e/**/*.ts"],
  extends: [playwright.configs["flat/recommended"]],
  rules: {
    "playwright/valid-title": ["error", { mustMatch: { test: "^should .+" } }],
  },
},
```

- `playwright.config.ts` permanece no bloco de config files existente (`*.config.{ts}`)
- Títulos de `test()` seguem o mesmo padrão do Vitest (`"should ..."`)

## lefthook — glob ESLint

```yaml
glob: "{app,components,lib,types,e2e}/**/*.{ts,tsx}"
```

Sem `e2e/` no glob, arquivos E2E não passam pelo ESLint no pre-commit.

## Scripts (`package.json`)

```json
{
  "start": "serve out -l 3000",
  "test:e2e": "playwright test",
  "test:e2e:ui": "playwright test --ui"
}
```

- `start` substitui `pnpm dlx serve out` — mesma porta e binário usados pelo `webServer`
- `test:e2e:ui` é conveniência local; critério de aceite é apenas `pnpm test:e2e`

## Fluxo de execução

```
pnpm test:e2e
  └─ Playwright inicia webServer
       └─ pnpm build          → gera out/
       └─ serve out -l 3000   → serve estático
  └─ Aguarda http://localhost:3000
  └─ Roda e2e/home.spec.ts (Chromium)
  └─ Encerra servidor
```

Em dev, com `pnpm start` já rodando na porta 3000, `reuseExistingServer` pula o rebuild.
