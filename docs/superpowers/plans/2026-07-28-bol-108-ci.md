# BOL-108 — CI no GitHub Actions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a GitHub Actions CI pipeline (`Verify`) that runs format, lint, typecheck, Vitest, and Playwright E2E on every push/PR to `development` and `main`.

**Architecture:** Single-job workflow in `.github/workflows/ci.yml` mirroring the `betting-pool` backend pattern. Steps run sequentially: format → lint → typecheck → test → playwright install → e2e. Build is validated implicitly by Playwright's `webServer` (`pnpm build && serve out`). A new `typecheck` script (`tsc --noEmit`) is added to `package.json`.

**Tech Stack:** GitHub Actions (`actions/checkout@v6`, `pnpm/action-setup@v6`, `actions/setup-node@v6`), pnpm, TypeScript, Vitest, Playwright

**Spec:** `docs/superpowers/specs/2026-07-28-bol-108-ci-design.md`

## Global Constraints

- Package manager: `pnpm@11.9.0`
- Node: `>=26.4.0` (`.nvmrc` with `26.4.0`)
- Workflow name: `Verify`
- Branches: `development`, `main`
- Steps order: format → lint → typecheck → test → playwright install → e2e
- No separate `build` step (build validated via E2E `webServer`)
- Playwright CI: `chromium --with-deps` only
- `paths-ignore`: `.vscode/**`, `.nvmrc`, `commitlint.config.js`, `lefthook.yml`, `README.md`, `docs/**`
- Commits: conventional commits with `scope-case: lower-case` (e.g. `ci(web): ...`)
- Out of scope: artifact upload, coverage, branch protection, multi-browser matrix, deploy

### Task 2: Create GitHub Actions workflow

**Files:**

- Create: `.github/workflows/ci.yml`

**Interfaces:**

- Consumes: `pnpm typecheck` from Task 1
- Produces: CI workflow `Verify` with all validation steps

- [ ] **Step 1: Create `.github/workflows/ci.yml`**

```yaml
name: Verify

on:
  push:
    branches: [development, main]
    paths-ignore: &paths_ignore
      - ".vscode/**"
      - ".nvmrc"
      - "commitlint.config.js"
      - "lefthook.yml"
      - "README.md"
      - "docs/**"
  pull_request:
    branches: [development, main]
    paths-ignore: *paths_ignore

jobs:
  verify:
    name: Verify
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v6

      - name: Setup pnpm
        uses: pnpm/action-setup@v6
        with:
          cache: true

      - name: Setup Node.js
        uses: actions/setup-node@v6
        with:
          node-version-file: .nvmrc

      - name: Install dependencies
        run: pnpm install --frozen-lockfile

      - name: Format
        run: pnpm format

      - name: Lint
        run: pnpm lint

      - name: Typecheck
        run: pnpm typecheck

      - name: Test
        run: pnpm test

      - name: Install Playwright browsers
        run: pnpm exec playwright install chromium --with-deps

      - name: E2E
        run: pnpm test:e2e
```

- [ ] **Step 2: Validate YAML syntax**

Run:
